# Novidades

O que mudou em cada versão do Evergreen, da mais nova para a mais antiga.

Cada linha é o título de uma PR, escrito para quem usa o app. O
`./scripts/bump_version` acrescenta a linha quando a PR entra na `validation`, e
o `./scripts/release` usa as mesmas linhas como notas do GitHub Release.
